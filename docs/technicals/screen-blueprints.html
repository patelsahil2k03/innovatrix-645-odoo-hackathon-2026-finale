Only one number here is stored

Committed is entered. Achieved, Achieved % and To-achieve are all derived on read, so they can never go stale — and the revision chain means a confirmed budget's history stays intact instead of being overwritten.

The security detail worth getting right

Requesting another contact's document returns 404, not 403. A 403 confirms the record exists, which leaks information across customers. No internal navigation appears here at all — not even disabled.

Build order

Which screen to write first

Do these first
  • App shell with the four menus and the trial-balance badge
  • Contact list + form — the template for every other master
  • Customer Invoice form with lines and the posting preview
  • Journal Entries list + detail
  • Balance Sheet with drill-down

That sequence is a complete demo on its own. Everything after it is breadth.

Then, by copying
  • Product, Analyticals — same shape as Contact
  • Sales Order, Purchase Order, Vendor Bill — same shape as Invoice
  • Kanban toggles for the three masters
  • Budget form and the revision chain
  • P&L, Budget Report, the portal

Get the first invoice screen genuinely right; the rest is repetition.
